# Vitrina PEZ

Vitrina virtual de la colección de dispensadores PEZ de David (vintage y modernos, Disney, superhéroes y más), con fotos, año, origen, estado y tasación en pesos chilenos (CLP). Incluye filtros, música de fondo y calculadora para ir sumando piezas.
